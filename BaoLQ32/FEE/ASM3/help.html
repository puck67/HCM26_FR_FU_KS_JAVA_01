System Help & Instructions

Register Visitor

To register a visitor, navigate to the Register tab and complete the form. Note the validation rules:

  • Fist name: Mandatory (max 20 characters, no numbers allowed).
  • Last name: Mandatory (max 20 characters, no numbers allowed).
  • You are in: Mandatory location selection.
  • Telephone: Optional (must be digits, max 11).
  • Email: Optional (max 50, standard email format).
  • Description: Optional (max 200 characters).
Go to Register

Search Visitors

To search registered visitors, navigate to the Search tab. Features include:

  • Universal Keyword Search: Filters the table across all columns including hobbies and description.
  • Real-time update: Results filter instantly as you type in the search bar.
  • Hover Highlight: Hovering your mouse over table rows highlights the selected item in green.
  • Persistence: The list dynamically includes both default mock data and newly registered visitors.
