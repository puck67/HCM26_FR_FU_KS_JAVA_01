System Overview

Manage the dynamic navigation menu tree and check role-based permissions.

Welcome back to the Dynamic Menu Management Portal!

This application implements a complete self-referencing hierarchy structure for menu items in a training application database. The sidebar automatically adapts and filters based on active menu items and the logged-in user's roles:

  • Admin User: Has access to User Management, Training Management, and System Management. Can add, edit, and delete menus.
  • Teacher User: Has access to Training Management (Subject and Course Management).
  • Student User: Has access to My Courses.
