How to Search

On the Search Visitor page, you can enter any keyword in the search input box and click the Search... button to filter visitors. The search will query against all fields in the database including First name, Last name, Gender, Telephone, Location, Hobbies, and Description.

Additionally, you can click on any row in the search results table to highlight or select it.
