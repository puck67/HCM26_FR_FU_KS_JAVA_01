Objectives  
After finishing the following exercises, trainees will: 
• Understand Spring Core (IoC, DI) 
• Practice with JDBC Templates to connect database in spring 
• Use JPA for object-relational mapping 
• Practice with the Spring MVC framework architecture 
• Know how to write a Web application with Spring  MVC Framework and Spring Data JPA 
Business needs 
Create a Web application based on HTML, CSS, JavaScript, Ajax, Thymeleaf, Spring framework.  
The Course Sharing System that we are going to develop is a single-instructor system (for this assignment).  
1. The Instructor of the system will be able to perform the following actions: 
• Login and logout  
• Create, update and delete Courses  
• Publish, unpublish and archive Courses  
• Approve and delete Reviews 
2. All other users are Students (guests) who can perform the following actions: 
• Read Course details and published content  
• Create Reviews (with a 1-5 star rating) 
3. Additional Requirements for this system include: 
The homepage of the system should display a list of the most recent, published Courses.  
• If a page contains more than 10 Courses, they should be displayed in pages.  
• The system should display a Course together with its approved Reviews.  
• The system should be able to list Courses with a specified Category.   
• The system should show a cloud of Categories indicating their use frequencies.  
• The system should show a list of most recent Reviews. 
Working Environments 
✓ JDK 1.8 + 
✓ Maven 3+ 
✓ Eclipse IDE or STS,  
✓ MySQL DB Server/MySQL,

Product Architecture 
Web applications are by nature distributed applications, meaning that they are programs that run on more than 
one computer and communicate through a network or server. Specifically, web applications are accessed with 
a web browser and are popular because of the ease of using the browser as a user client. 
 
 
The product is implemented using MVC Pattern base on Spring Web MVC.  
Technologies 
The product implements one or more technology: 
• HTML & CSS 
• JavaScript & Ajax 
• Thymeleaf 
• Spring Framework: IoC, Bean, SpEL, JdbcTemplate, Spring Data JPA, Interceptor, Validation, Spring 
Sercutity. 
Database Relationship 
Based on the analysis of the requirements, we decide  to use the following database tables to store the 
persistent data for our blog application: 
• tbl_instructor stores the instructor information, including username and password for login.  
• tbl_course stores the course information. It mainly consists of:  
o title: required, title of the course.  
o description: required, a short summary of the course.  
o content: required, full details of the course (uses Markdown).  
o status: required, status of the course (e.g., 1=DRAFT, 2=PUBLISHED, 3=ARCHIVED).  
o category: optional, a list of comma-separated words categorizing the course. 
• tbl_review stores the course review information. Each review is associated with a course:
