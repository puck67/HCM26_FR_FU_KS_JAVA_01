Help

FEE.P.A103 — Visitor management with validation, sanitize, BEM CSS, and pagination.

Register a visitor

  1. Open Person.
  2. Fill required fields (First name, Last name, You are in).
  3. Errors show at the top and under each field; blur validates one field at a time.
  4. Click Register — button is disabled while processing.

Search visitors

  1. Open Search.
  2. Enter a keyword (max 50 chars, sanitized) or leave empty to list all.
  3. Search matches every column, not only first name.
  4. Use pagination: rows per page and page navigation.

Validation rules (PDF)

  • First / Last name: required, max 20, letters only (no digits).
  • Telephone: optional, max 11, digits only.
  • Email: optional, max 50, [a..Z][0..9]@[a..Z].
  • You are in: required (Europe, Africa, Australia, Asia, America).
  • Description: optional, max 200 (live counter).

Project structure

  • css/styles.css — BEM, CSS variables (:root)
  • js/validators.js — Regex + sanitize (no DOM)
  • js/form-ui.js — Error UI via classes only
  • js/validation.js — Person form (blur / submit)
  • js/data.js — Data + re-validate on save
  • js/pagination.js — Paginator (event delegation)
  • js/search.js — Search + table
