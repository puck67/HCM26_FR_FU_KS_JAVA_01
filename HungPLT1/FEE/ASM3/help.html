Help & Support

1. How to Register a Visitor

Navigate to the Register page using the navigation bar. Fill in the required fields marked with a red asterisk (*) including First name, Last name, and Region. You can optionally provide Gender, Telephone number, Email, Hobbies, and a Description. Once ready, click the green Register button to submit.

2. Registration Validation Rules

The form enforces the following rules upon registration:

  • First Name: Mandatory, maximum length of 20 characters, must contain characters only (no digits).
  • Last Name: Mandatory, maximum length of 20 characters, must contain characters only (no digits).
  • Telephone: Optional, maximum length of 11 digits, must contain numbers only.
  • Email: Optional, maximum length of 50 characters, must follow the valid email pattern.
  • You are in: Mandatory, you must select one of the regions.
  • Description: Optional, maximum length of 200 characters.

3. How to Search Visitors

Navigate to the Search page. Enter a keyword (which could match a First name, Last name, Region, Hobbies, or any column value) and click the green Search button. The list will immediately filter the table to display rows containing that keyword. Leaving the field blank and clicking Search will display the full list.

4. System Requirements

The system runs fully offline by utilizing local resources. Data persistence is handled securely using the browser's localStorage, which stores newly registered visitor profiles.
