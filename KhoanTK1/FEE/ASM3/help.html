Help & Guide

1. Form Validation Rules (Register Screen)

When registering a new visitor in the Register Visitor page, the system enforces the following validation checks before saving:

Field Name Mandatory Max Length Validation Rules / Description
Fist name Yes 20 chars Must contain only alphabetical characters and spaces (no numbers or special symbols). Supports Vietnamese accents.
Last name Yes 20 chars Must contain only alphabetical characters and spaces (no numbers or special symbols). Supports Vietnamese accents.
Gender No - Select option from dropdown list (default is Male).
Telephone No 11 chars If provided, must contain numbers only (no spaces, letters, or symbols).
Email No 50 chars If provided, must match the valid email format structure (e.g., username@domain.com).
You are in Yes - Must select one of the available locations (Europe, Africa, Australia, Asia, America).
Hobbies No - Select one or more checkboxes corresponding to your hobbies.
Description No 200 chars Optional brief notes about the visitor (maximum 200 characters).

2. Search Visitor Instructions

  • Enter a search keyword into the text box labeled Fist name: in the Search Visitor screen.
  • The system will dynamically search and filter rows as you type (live search).
  • You can also click the Search... button to execute the query manually.
  • Multi-column Filter: As required by the assignment guidelines, the search matches the keyword against all columns in the visitor record (First name, Last name, Gender, Telephone, Continent/Region, Hobbies, and Description), making it easy to find records using any piece of information!
  • If the search field is left blank, all visitor records will be displayed in the results table.

3. Row Highlight Feature

Hovering your mouse pointer over any visitor record row in the search results table will dynamically highlight that row with a soft gold background color (#fef3c7). This is implemented via dynamic classes, ensuring table styles comply with the strict stylesheet requirement to not override cell backgrounds directly.
