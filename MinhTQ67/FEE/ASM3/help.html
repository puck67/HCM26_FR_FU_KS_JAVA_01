Help & Instructions

📋 About This Application

This Visitor Information App allows you to register visitor details and search through registered visitors. It was built using HTML5, CSS3, Bootstrap 4, JavaScript, and jQuery as part of the Front-End Essentials Project Assignment (FPT Software).

✏️ How to Register a Visitor (Person Page)
  1. Navigate to the Person page using the top navigation bar.
  2. Fill in the First name and Last name fields (both are mandatory, letters only, max 20 characters each).
  3. Select a Gender from the dropdown.
  4. Optionally enter a Telephone number (numbers only, max 11 digits).
  5. Optionally enter an Email address in the format example@domain.com.
  6. Select the region you are in under You are in (mandatory — choose one radio button).
  7. Check any applicable Hobbies (optional).
  8. Add a short Description (optional, max 200 characters).
  9. Click the green Register button to save your information.
🔍 How to Search Visitors (Search Page)
  1. Navigate to the Search page.
  2. Type any keyword into the First name search box.
  3. The search matches against all fields — name, gender, location, hobbies, telephone, description, etc.
  4. Press Enter or click the green Search... button.
  5. Matching visitors will appear in the results table. Rows highlight on hover.
  6. Clear the input to show all registered visitors.

💾 Data Storage

Visitor records are stored in your browser's localStorage. Data persists across page reloads within the same browser. Clearing your browser data will remove all records.
