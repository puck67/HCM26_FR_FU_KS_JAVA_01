# BT3_h2

Simple Java console app using H2 embedded database to manage stores.

Branch for push: `MinhTQ67`

Quick notes:
- The H2 DB file is `store_management_db.mv.db` and is ignored by `.gitignore`.
- Run with Maven:

```bash
mvn clean compile
mvn org.codehaus.mojo:exec-maven-plugin:3.1.0:java -Dexec.mainClass=main.Main
```

To push this project to GitHub on branch `MinhTQ67`, see commands in CONTRIBUTING or use the shell commands provided in the workspace.
