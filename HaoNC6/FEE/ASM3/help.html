Help & User Guide
📋 Person Page (Visitor Registration)

This page allows you to register a new visitor. Fill in the form fields below:

  • First name – Required. Letters only, max 20 characters.
  • Last name – Required. Letters only, max 20 characters.
  • Gender – Select from the dropdown (Male / Female / Other).
  • Telephone – Optional. Numbers only, max 11 digits.
  • Email – Optional. Must follow format name@domain.ext, max 50 characters.
  • You are in – Required. Select one region by clicking a radio button.
  • Hobbies – Optional. Check one or more hobbies.
  • Description – Optional. Free text, max 200 characters.

Click Register to save the visitor. Errors will be displayed if mandatory fields are missing or invalid.

🔍 Search Page (Find Visitors)
  • Type any keyword into the search box (name, region, hobby, or description).
  • Click Search or press Enter to execute the search.
  • Results matching the keyword across all fields will be displayed in the table.
  • Leave the search box empty and click Search to list all visitors.
  • Hover over a table row to highlight it.
