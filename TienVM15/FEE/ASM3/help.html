Registration Form Guide

When registering a new visitor, the following validation constraints must be satisfied:

Field Mandatory Max Length Constraints
First name Yes 20 Must contain letters only (no numbers or special characters).
Last name Yes 20 Must contain letters only (no numbers or special characters).
Telephone No 11 Must contain numbers only.
Email No 50 Must match valid email format.
You are in Yes - Must select one geographic region.
Description No 200 Optional textarea up to 200 characters.

Search & Filter Guide

  • The Search page allows keyword filtering across **all columns** (not just First name).
  • Type your keyword in the input box and click **Search...** to apply the filter instantly.
  • Hovering over any visitor row in the list table will highlight the row in light green.
